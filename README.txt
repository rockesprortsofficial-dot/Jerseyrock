ROCK ESPORTS 16-ANGLE JERSEY — GITHUB PAGES

यो package मा:
- index.html = सबै images HTML भित्रै राखिएको single-file website
- angle_01.jpg ... angle_16.jpg = 16 angle images (reference files)

GitHub:
1. index.html लाई repository को root मा upload/replace गर्नुहोस्।
2. Commit changes गर्नुहोस्।
3. Settings → Pages → Deploy from branch → main → /(root) → Save.
4. 1–2 मिनेटपछि site refresh गर्नुहोस्।
